# HorseMD v0.13.29

`0.13.29` 是 `v0.12.62` 之后的首个正式发布候选，合并了其后的桌面开发测试版本。本次重点不是继续堆叠功能，而是把**源码 / 富文本一致性、长文档写作和常用编辑操作**做得更可靠。

## 新功能

### 源码 + 预览双栏（[#107](https://github.com/BND-1/horseMD/issues/107)）

- 在富文本编辑区右键选择“源码 + 预览”，左侧编辑 Markdown 源码，右侧实时显示只读富文本效果。
- 两侧按当前内容位置联动滚动；图片、表格和代码块高度不一致时仍定位到相近段落，而不是机械同步滚动条百分比。
- 右侧支持滚动、选择和复制，但不会显示块柄、格式工具或编辑右键菜单，也不会因为点击预览而产生未保存状态。
- 该模式仅用于桌面 Markdown 文档；纯文本、快速打开的重文档、移动端和双文档分屏期间不会提供入口。

### 拖入文件或文件夹直接打开

- 从 Finder 或文件资源管理器把一个或多个文件拖到 HorseMD 窗口，会分别作为标签打开。
- 把文件夹拖到窗口会加入多根工作区，文件夹原位置和内容不会被移动或复制。
- 文件与文件夹可在同一批拖入；无效或已经移动的路径会被忽略，不影响其余项目。
- 把图片拖到富文本正文仍按图片插入处理，不会误开成图片标签。

### 恢复文档光标与阅读位置（[#111](https://github.com/BND-1/horseMD/issues/111)）

- 重新打开文档时恢复上次的光标和滚动位置，长文档无需每次重新寻找写作处。
- 富文本、源码模式和快速打开的重文档都支持位置恢复。
- 文件被外部修改、长度发生变化时不会套用旧位置，避免把光标恢复到错误内容。

## 改进

- **表格单击编辑**：单击 Markdown 表格单元格即可直接放置光标，不再需要先选中表格再双击。
- **代码块行号**（[#109](https://github.com/BND-1/horseMD/issues/109)）：编辑器代码块使用贴左、全高、不透明的行号栏和分隔线；导出 PDF 时同步保留行号。本次完成该 Issue 的行号与分隔线部分，“PDF 代码块背景可配置”仍未纳入。
- **原生 HTML 表格自适应**：带固定宽度或 `width="100%"` 的 HTML 表格会跟随正文宽度收缩，窄排版下不再被裁掉或撑宽整个页面。
- **本地 Markdown 链接**：富文本中的 POSIX 绝对路径、Windows 盘符路径、UNC、`file://` 与相对路径都可通过 `Ctrl/Cmd + 点击` 打开；普通网络链接仍交给系统浏览器。
- **未保存状态即时反馈**：富文本输入、删除、粘贴或拖放后，标签和底部状态立即显示未保存，不再等待 Markdown 缓存异步更新。
- **源码行首定位**：源码模式和“源码 + 预览”左侧可以准确点击到非空行第一个字符之前，光标不再覆盖首字符。

## 修复

### 富文本与 Markdown 原文保真

本版集中修复一整组“富文本看起来已修改，但源码、保存或重开仍是旧内容”的问题：

- 富文本删除正文、列表、引用或整篇内容后，切换源码、保存和重新打开不再让旧内容复活。
- 富文本只更新实际编辑的区域；未触碰区域原有的空行、CRLF/BOM、紧凑/松散列表和列表符号不会被整篇序列化器重写。
- 逐字输入 `-`、`+`、`*` 创建或继续无序列表时保留实际输入的符号，不再统一变成 `*`。
- 空段落和空列表项使用的编辑器内部 `<br />` 占位不会泄漏到用户源码。
- 行首连续空格不再变成可见的 `&#x20;`；模式切换、保存和重开保持同一内容语义。
- 列表正文中的字面 `1.`、`1)`、`-`、`+`、`*` 不再被额外写成 `1\.`、`\-` 等序列化器转义。
- `- 1. 内容` 这类会被 Markdown 解析器识别为嵌套列表的文本，在编辑、删除、拆分和列表转换后仍能安全写回作者源码。
- 多个段落与列表之间连续执行“输入 → 删除 → 再输入”时，不再遗漏新增内容或保留已删除内容。
- 源码 / 富文本切换继续跟随当前编辑点；空段落、列表、表格、代码块和重复文字附近不会随意跳到另一行。

### 反引号与行内代码

- 行内代码只在用户完整输入 `` `内容` `` 的最后一个反引号后渲染，不会在首个中文字符提交时提前进入代码样式。
- 闭合后光标默认位于代码外；点击已有行内代码后，可用 `←` / `→` 自然移出首尾边界。
- 单个、两个或三个普通反引号不会吞字符；删除代码围栏后立即继续输入、切源码或保存，不再触发“保存已暂停”或锁住源码模式。
- 在新建文档中输入同一行 ```` ```你好``` ````，源码、保存和重开不会凭空增加反斜杠。
