# HorseMD v0.13.187 发布说明

`0.13.187` 是 `v0.13.29` 之后的首个正式发布，合并其间 77 个提交。本次主线是把**富文本与源码的一致性**做彻底——引入事务证据链架构，让每一次编辑（含中文输入法、未存盘新文档、嵌套列表、粘贴）都有可证明的源码映射，而不是靠序列化器猜测——同时修复一批真实使用中报告的问题。

## ✨ 新功能

### HTML 表格中的 LaTeX 公式直接渲染

- 用 HTML 语法写的 `<table>` 表格，单元格里的 `$C_1$`、`$x_1$`、`$\overline{C}$` 等公式现在在**编辑器里直接渲染**成数学排版，与正文公式外观一致（此前显示为原始 `$...$` 文本）。
- `$$...$$` 块级公式同样支持。
- 仅影响显示：`.md` 文件里的原始字节完全不变，其他 Markdown 软件打开仍是原样。
- 导出 HTML 时表格内公式同步渲染。

### 顶部标签栏支持鼠标滚轮横向滚动

- 文件标签多到溢出时，直接在标签栏滚动滚轮即可横向翻阅，不再需要 Shift + 滚轮。
- 触控板原生横向手势、Ctrl 缩放不受影响。

## 🐛 修复

### 富文本 / 源码一致性（本次主线）

本版用「事务证据链」架构重构了富文本编辑到源码同步的整条通路：每次按键先捕获带修订号的 ProseMirror 事务证据，由专注的规则族**证明**该改动的源码映射后发布，无法证明时保持源码不变并明确提示，绝不整篇重写。集中修复：

- **中文输入法 + 立即回车的组合**（输入文字后马上按 Enter 拆分段落/列表项）不再出现"检测到富文本与源码不一致"警告，也不再丢失刚输入的字。
- **未存盘的新文档**（scratch）上的引用、列表、嵌套列表编辑不再误报警告。
- **嵌套列表按 Tab 缩进 / Shift+Tab 反缩进 / Enter 拆分 / Backspace 合并**的源码映射全部由专项规则族拥有，嵌套层级、缩进、列表符号不再错位。
- **有序列表退格删除链**（逐字删除穿越嵌套层级）不再把嵌套项错误发布成顶层项。
- **同一文档粘贴两次**（粘贴 → 存盘 → 全选清空 → 再粘贴）不再触发误报警告——这是发布顺序竞态，不是内容分歧。
- **任务清单勾选**、表格行列增删、单元格文字编辑、代码块语言与内容修改等的源码保真全部改为事务证明。

### 列表符号（`-` / `*` / `+`）保真

- 手打 `-` 创建的无序列表，在任何操作后**始终保持 `-`**，不再一会儿变成 `*` 一会儿变回来：
  - 嵌套列表项末尾按 Enter 退出到新行时，新行继承 `-`；
  - 新空行按 Tab 缩进成嵌套项时，继承父层的 `-`；
  - 输入文字、删除、拆分、合并全程不再翻成序列化器默认的 `*`。
- 与 Typora / Obsidian 等软件互操作时不会因符号翻转产生全文 diff。

### 复制有序列表到微信等编辑器不再数字换行

- 从 HorseMD 复制有序列表粘贴到微信公众号等编辑器，`1.` `2.` `3.` 数字**和文字在同一行**，不再出现数字单独一行、正文掉到下一行。
- 复制列表中段时编号连续（不会每项都从 1 重新计）。
- 纯文本粘贴时数字同样保持行内（此前纯文本模式的数字会整个丢失）。

### 云同步连接表单报错不再清空

- 填写 WebDAV / S3 连接信息提交失败（地址错误、鉴权失败等）时，表单**保留全部已填内容**。
- 有问题的字段红框标出，错误原因显示在该字段下方；修改任一字段即清除对应标记。
- 不再需要全部重填一遍。

### 其他修复

- 大表格（含固定宽度 HTML 表格）在交互期间不再丢失滚动位置。
- 分叉后的有序列表 marker 在源码同步中保持作者拼写。
- 手打尾部长代码围栏（连续输入不暂停）正确写入源码。
