# HorseMD v0.13.224

本版本为正式发布版本。升级前建议备份重要文档；已知问题和验证范围见下文，正式发布不代表所有一致性及性能问题已关闭。

## 🐛 修复

- 修复表格纯文本单元格删除至空、再通过中文输入法填写时可能中断源码同步的问题。只修改目标文字，保留其他行列与原始排版。
- 修复删除列表内空段落后，已等价的源码仍被搁置，导致后续编辑沿用旧基线的问题。
- 修复大文档延迟同步可能先处理新内容、后处理旧内容的时序问题；强制保存和切源码后使旧任务失效。
- 减少诊断日志重复全文快照，以及无评阅正文逐键重复定位的开销。

## 验证范围与已知限制

本次表格故障副本已验证“否→空→是”真实输入法操作、正常同步与立即切源码、整份源码逐字比较、列数、磁盘保存和独立配置冷重开。相邻表格编辑、空单元格规范化、协调器、调度与39项源码保真探针通过。

**全局源码/富文本一致性P0及P7c仍未关闭。Redis大文档停止输入后约1.9秒的整篇同步长任务仍待优化。** 有警告或保存暂停时，不要用最后一次恢复成功替代完整内容核验。

## 📦 下载与安装

使用本版本Release附件中的对应平台安装包。Windows安装包为x64 NSIS安装器；macOS按arm64/Intel架构选择。构建和归档校验成功不等于完成Windows真机安装验收。

应用未进行商业代码签名，操作系统可能显示未知发布者提示。核对来源和校验值后决定是否运行，不要关闭系统安全防护。

需要取证时先退出旧进程，再以`--horsemd-input-trace`启动已安装应用。系统临时目录中的`horsemd-input-trace-<pid>.jsonl`对应本次进程。反馈时附对应PID日志与触发动作；日志可能含文档内容，分享前检查敏感信息。
