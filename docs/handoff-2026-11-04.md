## 3. 修掉的问题（都可能被用户碰到）

- 行内序列化重写（`lib/inline-serializer.js`）：交叉格式里空格挪位、只剩空格的格式写成 `****`、链接被行内代码切开；空白 / 换行只在真边缘移出；反复建树到稳定（再存不变）；相邻 `*` 换 `_`；soft break 前的反斜杠转义；换行前的行内 HTML 不再被 mdast 改成空格。
- 中文友好删除线（`lib/remark-cjk-strikethrough.js`，按名替换 GFM 的 `~~`）。
- 链接里的行内代码不再被去掉（删了 `editor-link-labels.js`）。
- 校验器 / 重排：删除线、高亮、上下标边缘空白容忍；Unicode 空白（`lib/markdown-blanks.js`）；`marker`（`*`/`_`）不算差异；先严格校验，Option A（字面 `*`）只在写不出时用；图片 / 公式的 mark 参与比较。
- 序列化缓存把「只差图片格式」的文档当成同一个（`sameIgnoringHeadingIds` 不比叶子 mark）→ 只给图片加粗保存丢格式。
- 任务项以格式开头时整段重排丢复选框（`lib/remark-task-paragraph-position.js`）。
- 上下标：跨兄弟节点配对（里面可以有格式）、实体对齐、`<sub>`/`<sup>` 在开启时就是上下标、贴着 `~~` 时写成 HTML；在高亮解析之前运行。
- 代码块转正文 / 标题、Delete 合并代码块后暂停：换行节点设为 `linebreakReplacement` + `editor-textblock-newlines.js`。
- 单个 `=` 被高亮且旁边有 `=` → 写成 `<mark class="hm-hl-yellow">`。
- 两个反斜杠 + 软换行被作者风格改成硬换行（`serializer-style.js` 看奇偶）。
- 行内代码盖住图片会丢图（`editor-inline-code-atoms.js` 不让代码 mark 落在图片 / 公式上）。
- 规范语料暴露的重排问题：制表符 / 深缩进代码、列表接列表、只有表头的表格、`[](url)` 和只有定义的文档、相邻两个区域编辑重叠（fuzz 种子 33）。
- Windows：改设置后崩溃 / 强制退出会丢设置（`storage:flush` → `flushStorageData()`）。
- 过期测试：`test-markdown-sync-scheduling`、`test-editor-source-map-scope`、`test-keybindings-persistence-ui`（mac 快捷键写法）。
- 另：慢慢拖选时工具栏中途消失（`editor-toolbar-autohide.js`，计时从松开鼠标开始）；云端连接服务图标换成各家官方 logo（`assets/providers`）。
