# HorseMD 官方同步：调研与设计（2026-11-20）

用户决定（2026-11-19）：App 在所有平台免费下载。收入来自我们自己运营的同步服务，模式同 Obsidian Sync。接自己的坚果云、WebDAV、S3 的同步继续免费。

本文的结论来自三路调研（官方文档、源码、价目页，2026-11-20 查）。标「未核实」的结论没有一手来源。

## 1. 成熟产品怎么做

| 产品 | 服务器 | 加密 | 冲突 | 价格（年付折月） |
|---|---|---|---|---|
| Obsidian Sync | 自建，WebSocket 实时；新加坡、法兰克福、旧金山、悉尼四个机房，建库时选 | 默认端到端：AES-256-GCM，scrypt 从库密码派生密钥；路径也加密 | Markdown 用 diff-match-patch 自动合并，可改为冲突副本 | Standard $4（1 GB，单文件 5 MB，历史 1 个月）；Plus $8（10 GB，200 MB，12 个月） |
| 思源 | 服务器给客户端签发上传凭证，客户端直传**七牛** | AES-256-GCM，内容分块、zstd 压缩；scrypt 的 salt 取密码本身的哈希（缺陷） | 三方判断，输的一方另存冲突副本 | 国内 ¥148/年，含 8 GB；iOS 有 IAP |
| Logseq Sync | 客户端拿临时 AWS 凭证直传 S3（来自非官方项目，未核实） | age 格式，文件名也加密 | 未核实 | $5–15/月 |
| Joplin Cloud | 开源的 Joplin Server，按「条目」同步 | 随机主密钥，用密码加密主密钥（PBKDF2-SHA512 22 万次） | 冲突笔记 | €2.4–4.8/月，带 14 天试用 |
| Standard Notes | 服务器只当不可信存储 | Argon2id，随机条目密钥由主密钥加密 | — | $90–120/年 |

大家共同的做法：
1. 账号和同步库分开：先登录账号，再新建或连接一个库，然后设加密密码。
2. 加密在客户端完成，文件名也加密。服务器能看到时间、设备、文件数和大小。
3. 套餐按存储量、单文件上限、历史版本长度分档，每月 $4–10。

## 2. 方案：服务器只管账号，文件直传对象存储（思源 / Logseq 的路子）

```
桌面 / 手机 ──登录、续期──▶ HorseMD 账号服务（账号、订阅、配额、签发临时凭证）
     │                               │ STS：只能读写 users/<uid>/ 的 1 小时凭证
     └──── S3 协议（现有 S3Provider）──▶ 对象存储（七牛国内区，见 §5）
           内容和文件名先在本机加密（EncryptedProvider）
```

- 在 App 里，官方同步就是「又一个服务商」。现有的清单、三方合并、冲突副本、本地版本历史、刹车、节流全部照用，不重写引擎。
- 服务器代码很少：一张账号表、订阅状态、调用 STS。它不经手文件流量，带宽成本最低。
- 配额怎么控：临时凭证本身管不住用量。服务器定期统计每个前缀的用量，超额后不再签发写权限，只给只读。Obsidian 超额后也是停止上传、不删数据。
- 第一版用轮询，沿用现在的「保存后 30 秒、启动、回到前台、5 分钟兜底」。以后再加一个「有变化」的推送通道，做到 Obsidian 那样的实时。

## 3. 账号

- 起步用 App 内「邮箱 + 验证码」登录，换回刷新令牌，存进系统钥匙串。以后按 RFC 8252 加上「在浏览器里登录」。
- 不用 Firebase（国内不可靠）。不用 LeanCloud（2027-01 关停）。Supabase、Clerk 在国内能否访问没有核实。所以自建：Node + SQLite，代码量很小。
- 短信登录以后再加：阿里云「短信认证」允许个人实名用户用它预置的签名发验证码（单价未核实）。

## 4. 端到端加密（第一阶段，已实现）

照 rclone crypt / Cryptomator 的做法：在任意服务商外面包一层。官方同步默认开启（Obsidian 的默认值），自己的 S3 / WebDAV 也能选用。

- **密钥**（Joplin / Standard Notes 的做法）：随机生成 32 字节主密钥，用密码加密后存在工作区的 `.horsemd/encryption.json`（明文 JSON）。改密码只重新加密这把钥匙，不用重传数据。
  - 密码派生：PBKDF2-SHA256，60 万次，随机 16 字节盐（OWASP 2023 的建议值）。WebCrypto 原生支持，桌面和手机都不用另装库。scrypt 和 Argon2 需要 wasm，以后可以用 `kdf.name` 升级。实测本机生成加解锁一次约 100 ms。
  - 主密钥用 AES-256-GCM 包裹。内容密钥和文件名密钥都由主密钥用 HKDF 派生。
  - 钥匙文件里有一个校验值（文件名密钥对固定串的 HMAC）。设备在每轮同步第一次读写前先核对。别的设备换了密钥、或云端被清空时，会停下并要求重新输入密码，绝不会把云端当成空库再写进去。
- **文件内容**：`HMX1` + 12 字节随机 nonce + AES-256-GCM 密文。内容不绑定路径，所以云端回收站的服务器端复制照样能用。任何改动都会被发现。
- **文件名**：整条路径做 HMAC-SHA256，变成 `o/<64 位十六进制>`。云端看不到文件名，也看不到文件夹结构，这一点比 Obsidian 更严：Obsidian 只加密路径。名字长度固定，不会超出 WebDAV 的 255 字节限制。回收站副本放在 `t/<时间>/<hmac>`，以后清理时能按时间找到旧的。
- **清单**：和普通文件一样加密。空文件夹只记在清单的 `dirs` 里，云端没有标记。
- **云端还能看到的**：文件数量、大致大小、修改时间、请求来自哪个 IP。这和 Obsidian 一样。
- **忘了密码**：无法找回（所有家都这样）。设置时要明确告诉用户，并提示把密码存进密码管理器。

代码：`src/shared/sync/sync-crypto.js`、`src/shared/sync/encrypted-provider.js`。测试：`npm run test:sync-e2ee`，内容如下：
- 钥匙文件：错误密码、改密码、损坏、NFC 和 NFD 写法的密码。
- 两台设备用真实引擎走完上传、下载、两边同改后合并、删除和回收站。
- 逐个扫描云端对象，确认不含文件名、正文、清单字段。
- 错误密钥、密钥被替换、钥匙文件被删时都会停下，并且不写入任何东西。

## 5. 存储、成本、合规（要你拍板）

**存储**（1000 个用户 × 1 GB 存储 × 每月下载 2 GB 的估算）：

| 选项 | 月成本 | 国内速度 | 说明 |
|---|---|---|---|
| 七牛国内区 | 约 ¥700 | 快 | 思源用的就是它；支持兼容 AWS 的 STS。能否按前缀限权、PUT 能否带 If-Match，**要用真实账号实测** |
| 腾讯云 COS 国内 | 约 ¥1,140 | 快 | STS 按前缀限权有文档；要给 S3 代码加子域名式地址 |
| 阿里云 OSS 国内 | 约 ¥600–1,120 | 快 | 2025-03 以后的新账号必须绑已备案的域名 |
| Cloudflare R2 | 约 ¥250 | 不稳（高峰期走国际出口） | 有前缀临时凭证接口和条件写；适合海外用户 |
| 香港（OSS / COS） | 约 ¥1,600 | 一般 | 不用 ICP 备案；流量贵 |

笔记类数据实际下载量应远低于每人 2 GB，真实成本会低很多。账号服务器放香港轻量机，每月约 ¥30–100（未核实）。

如果国内厂商不支持 PUT 的 If-Match，清单改为「编号递增的清单文件 + 禁止覆盖写」，效果相同。

**合规和收款**：
- 在大陆用服务器做付费服务，要「经营性 ICP 许可证」，**只有公司能办**（省内注册资本 100 万起）。个人和个体户只能办备案，不能经营。
- 服务器放境外（香港、新加坡），面向大陆用户，照样适用《个人信息保护法》，第 53 条要求指定境内代表。
- 收款：
  - 个人能用的是 **Paddle**：它作为代收方代缴各国税，个人做身份认证就行，结账页支持微信支付和支付宝。大陆个人怎么收到回款，未核实。
  - 支付宝、微信官方收款至少要个体工商户执照。
  - Stripe 不给大陆开户。Lemon Squeezy 已停止新注册。
- **iOS**：
  - 规则 3.1.3(b)：网页买的订阅可以在 App 里用，但 App 内也要能用 IAP 买。
  - Obsidian、Joplin、Logseq 的 iOS 版都没有内购，只能登录。但 2026 年有新 App 按这种做法被拒的报告。
  - 思源上了 IAP。稳妥的做法是同时上 IAP，小型企业计划抽成 15%。
- **Google Play**：可以做「只消费」，App 内只登录、不卖。现在直接发 APK，不受影响。

## 6. 分阶段

1. **端到端加密层**（已完成，见 §4）。
2. **在设置里用起来**（2026-11-20 已完成）：给自己的 S3 / WebDAV 新建同步文件夹时可选「端到端加密」。
   - 新建时设密码（至少 8 个字符，两次一致）；加入时列表标出「已加密」，先验证密码，错了文件夹不变。
   - 解开的密钥存进本机凭据库（桌面 safeStorage，手机 Keychain / Keystore），停止同步时删除。
   - 改密码只重新包裹密钥，其他设备不用重新输入。
   - 同步打不开时（本机没有密钥 `e2ee-locked`、别的设备换了密钥 `e2ee-key-changed`、云端丢了钥匙文件 `e2ee-key-missing`）按刹车处理：什么都不写，文件夹下面出现密码框，自动同步提示「需要确认」。
   - 不加密的文件夹遇到已加密的云端副本也会停下，绝不写明文；以前不加密同步过的文件夹不能直接改成加密。
   - 测试：`test:sync-e2ee-service`（真 Apache WebDAV + S3 模拟，多台设备 12 个场景）、`test:sync-e2ee-ui`（两个 App 实例走设置界面）、`scripts/test-sync-e2ee-phone.mjs`（安卓真机 WebView 和电脑互通）。
3. **账号服务原型**：Node + SQLite，邮箱验证码登录，签发凭证。
   - 先接本地的 S3 兼容服务做开发测试。
   - App 里加「HorseMD 同步」服务商：登录、看用量、续期凭证。
4. **对象存储实测**：要七牛（或 COS）的测试密钥，测 STS 前缀限权、条件写、限权后的列目录，再测国内外速度。
5. **收费**：Paddle 网页结账，订阅状态回写账号服务；iOS 按 §5 的结论决定是否上 IAP。
6. **上线**：隐私政策、App Store 隐私问卷（会变成「收集邮箱」）、欧盟交易商身份改为「是」、套餐和价格。
