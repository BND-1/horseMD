# PNG 图片导出实施方案

建立：2026-09-24。起点：0.13.231。状态：方案/先决测试阶段，尚未交付。

## 产品决策与依据

默认「分页图片（推荐）」：短文一张，长文按排版页输出连续编号的PNG；单张保存文件，多张一次选父目录后创建独立文件夹，不覆盖原文件。另提供「拼接长图」：将相同分页预览按顺序纵向拼接，明确保留页间留白，不伪称连续无分页截图。超过像素或长边预算，导出前阻止并提示切回分页/降低分辨率，不自动缩小字体、不截断尾部。

参考的实践（查阅于2026-09-24）：
- Typora官方Image导出说明：可设宽度/字号/清晰度；过长文章可能因性能与最终图片大小而失败。https://support.typora.io/Export/#image
- Marp官方CLI：--images png逐页输出，命名.001.png等；--image-scale独立控制分辨率。https://github.com/marp-team/marp-cli#convert-to-pngjpeg-images-
- W3C CSS Fragmentation：break-before/after/inside及widows/orphans管理分页，比等像素切片更适合文档。https://www.w3.org/TR/css-break-3/
- Electron printToPDF与Mozilla PDF.js Canvas渲染：复用已存在的分页排版，将每页按指定像素尺寸渲染。https://www.electronjs.org/docs/latest/api/web-contents#contentsprinttopdfoptions https://mozilla.github.io/pdf.js/examples/

不能把这些产品说成全部实现了HorseMD拟定的自动保护策略；预算和交互是本项目的设计选择。

## 首版范围

桌面Windows/macOS/Linux：PNG入口与PDF/HTML并列，命令面板/原生菜单/文件树及标签导出可达；移动端明确capability=false，不显示不能工作的入口。

独立图片导出窗口：模式、阅读卡片3:4/A4、正文大小、图片像素宽度；显示预览页数、单页尺寸、长图尺寸/保护提示、页预览；保存显示逐页进度、允许取消。白底文档排版，沿用导出样式；不承诺复刻任意用户CSS、编辑器滚动/选区/工具栏或动态媒体。缺失/超时资源必须提示并禁止直接导出，不能静默缺图。

PDF仅为内存中的排版中间结果，用户输出仍只有PNG。使用现有结构化getExportSourceForTab快照、图片暂存/公式/图表生成和安全打印流程；不截屏幕、不从未挂载的DOM猜测全文。首版拼接保留分页留白；无缝长文版式、透明底、JPEG/水印/社交模板为后续功能。

## 长文与性能保护

分页默认逐页渲染、逐页IPC落盘，一次只保留一页高分辨率Canvas，完成后释放。不把全部PNG Base64堆在React状态中。预览只渲染当前页，不一次绘制上百页。

初始应用预算（非浏览器通用上限）：长边16384px、每张2400万像素、最多200张、总6亿像素、单PNG最多32MiB、任务总输出512MiB；规划阶段先验证。长图只有在整张尺寸预算内才能申请Canvas。超大文档提示使用PDF或调小字号/分辨率，不以返回成功但少导几页解决。

## 实施顺序

1. 先决快照核验：122行代码（含空行/末行）和普通源码单换行必须进入导出快照；若发现旧缺陷单独修复、测试、patch提交。
2. PNG共享参数与尺寸规划纯函数；主进程按用户原生选择建立sender绑定会话，严格顺序接收PNG、校验尺寸和预算、暂存、完成时发布；取消/出错仅清理本任务创建的暂存目录。不接受renderer指定任意输出路径。
3. 图片导出窗口复用分页预览数据；顺序Canvas渲染PNG，所有设置变更使旧预览/计划失效，导出使用冻结快照；取消、关闭、渲染失败清理资源。
4. 接通菜单/命令/标签/文件树、preload与移动capability；中文和英文文案、教程、更新日志。
5. 单元/主进程临时目录测试、真实UI产物测试、长文/公式/表格/图片/长代码/原文不变/取消；相邻PDF/HTML与源码保真回归；两端构建。
6. 小步本地提交，打包安装最新app，带--horsemd-input-trace启动并核验路径/PID/日志。未另行授权不推送或发布。

## 验收底线

导出源、源码视图和磁盘不因导出改变。读的是完整当前文档而非只渲染了的代码行。实际PNG逐张可解码、尺寸/数量正确，首尾内容存在；分页不作裸像素切片，正常段落/代码行/表格行按排版分页，超大不可分内容必须通过实际产物检查。重试不能覆盖上一批、取消不能留下一批看似完成的图片。Windows原生交互未测则明确标记，不能把LF/CRLF或Mac打包当Windows验收。
