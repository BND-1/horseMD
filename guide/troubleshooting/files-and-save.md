# 文件与保存

<span class="version-badge">适用于 HorseMD v0.13.29</span>

## 工作区会复制文件吗

不会。桌面端添加文件夹只是把真实磁盘目录挂到文件树，重命名、移动和删除都会作用于真实文件。移除工作区根目录只取消显示，不删除目录。

## 未命名草稿在哪里

有内容且未保存的临时标签会随会话恢复，并保持“已修改”。它存放在 HorseMD 用户数据中，不是已经创建的 `.md` 文件。重要内容应使用 `Ctrl/Cmd+S` 保存到明确位置。

## 外部程序改了文件

HorseMD 监听已打开文件和工作区目录。磁盘变化会刷新文件树；当前标签没有未保存内容时会自动同步新内容。若你正在编辑，应用不会直接用外部版本覆盖，而是弹出提醒：本地未保存内容已保留。之后保存时，HorseMD 会合并两边的修改：改的是不同地方，就保存合并后的内容；改到了同一处，原文件保留外部版本，你的内容另存为“文件名 (冲突副本 设备名 时间).md”，标签页会切到这份副本，两边的内容都不会丢。

## 富文本保存会重新排版整篇源码吗

不会。HorseMD 会保留一份作者原始 Markdown，只把富文本中实际修改的区域写回去。没有触碰的列表符号、空行、CRLF/BOM、紧凑或松散列表不会因为一次普通编辑被整篇格式化；编辑器内部用于空段落的 `<br />` 也不会写入源码。

列表类型转换、标题转换等结构操作会修改被操作的当前块，这是用户明确触发的变化；其父级、子级和其他段落仍应保持原样。需要逐字符控制复杂反斜杠、LaTeX 或特殊 Markdown 结构时，建议直接使用源码模式。

如果出现“检测到富文本与源码不一致”，或保存时提示“原文件未被覆盖……请选择位置保存一份恢复副本”，说明 HorseMD 没能把这次富文本修改准确写回 Markdown，于是选择不覆盖原文件。这两条是同一个问题：编辑时看到前者，保存时看到后者。此时不要关闭标签，先按提示保存一份恢复副本。

这些提示上有「查看详情」按钮，点开后可以看到这次问题的详情：版本、出错原因、改动位置附近的内容（文件里原来的样子和编辑器里现在的样子），以及最近的按键操作。可以直接在框里删改不想公开的内容，然后任选一种方式发给我们：点「在 GitHub 提交」打开已经填好的问题反馈页面；或点「复制，微信发给作者」，在微信里把详情发给作者（微信号 `alwaysraiseuplikesun`）。有了这份信息，我们通常不需要你的整个文件就能找到原因。

## Android 文件管理器看不到文档

Android 可能禁止普通文件管理器浏览应用目录。请在 HorseMD 文件树中打开，或使用“导出/分享”复制到公共目录。卸载前必须导出重要文档。

## 图片或附件移动后失效

相对路径以 Markdown 文件目录为基准。移动文档时应同时移动关联的图片文件夹和 `assets/`。在源码模式检查链接是否仍指向正确相对位置。

::: tip 反馈时提供路径类型
报告文件问题时说明是绝对路径、相对路径、`file:///` 链接、网络地址，还是移动端系统 URI；不要公开包含敏感信息的完整个人路径。
:::

## 找回旧版本和删除的文件

HorseMD 会在这台电脑上自动保留文件过去的版本，不用做任何设置：

- **保存时**：保存前磁盘上的内容会留一份（同一个文件约 5 分钟最多一份；一次删掉大段文字时一定会留）。
- **同步更新或删除文件前**：原来的内容一定会留一份。
- **恢复旧版本前**：当前内容也会留一份，恢复错了可以再恢复回来。

找回的方法：

- 在文件树里右键文件，或在标签页上右键，选“**历史版本…**”（命令面板里也有）。左边按时间列出版本，右边是那个版本的全文；勾选“只看改动”可以和现在的内容对比。点“**恢复此版本**”就回到那时的内容；“**永久保留**”的版本不会被自动清理。
- 删掉的文件：在命令面板选“**最近删除…**”，或到“设置 › 通用 › 保存与恢复”点“最近删除…”。选中文件后点“**还原**”，它会回到原来的位置（那里已有同名文件时，会另存为带“已恢复”字样的新文件，不会覆盖）。

历史版本只保存在这台电脑上（应用数据目录里的 `history` 文件夹），不会放进你的笔记文件夹，也不会同步到云端。默认保留 30 天，可以在“设置 › 通用 › 保存与恢复”改成 90 天或 1 年，那里也能看到已用空间（上限 1 GB）和清空历史。占用一般很小：普通使用一个月约几 MB。
