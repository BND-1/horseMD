# 表格

<span class="version-badge">适用于 HorseMD v0.13.29</span>

## 插入表格

在空段落输入 `/表格`、`/table` 或拼音首字母 `/bg`，选择表格命令。默认会插入一个可继续扩展的表格。也可以粘贴标准 GFM 表格源码。

**单击单元格即可直接编辑**（不需要双击），光标落在点击位置；双击仍可选中文字。使用表格边缘的控制按钮添加或删除行列。长文本和行内代码会在列宽内换行，不会覆盖相邻单元格。

表格行高会随“设置 → 外观 → 排版”中的文档字号一起变化。调小字号时单元格的上下留白也会同比收紧，不会继续占用固定高度；导出 PDF 时采用同样的紧凑比例。

点击行或列手柄选中整行、整列后，可使用出现的操作菜单调整列对齐或删除选中内容。菜单会在鼠标移开后短暂停留；移动到菜单内时会持续显示，方便完成操作。

## 宽表和列宽

内容较少的表格会按内容保持自然宽度，不会自动拉满整条编辑区。HorseMD 会综合表头和每一行单元格的内容自动分配列宽：短编号列会更窄，包含较长说明的列会更宽，不会默认把所有列等分。编辑单元格内容后，尚未手动调整过的表格会继续自动匹配。

导出 PDF 时会沿用正文中已经显示出来的表格总宽度、列宽比例和紧凑行距。紧凑表不会被强制铺满整页，短列和长列也不会重新等分；单元格内层段落不会额外撑高每一行。超出打印区域的宽表才会按页面宽度整体收敛并换行，保证右侧内容不会被裁掉。PDF Studio 中看到的页面就是最终保存的同一份 PDF。

列数较多或单元格内容较长时，只有表格自身出现横向滚动条，正文页面不会被撑宽。

如果阅读时更希望一次看到所有列，可以到 **设置 → 外观 → 表格** 开启“宽表自动换行”。该区域位于自定义 CSS 下方，开关下方会用同一段长单元格即时展示两种效果：关闭时保持单行并可横向滑动，开启后在当前宽度内折行。开启后，Markdown 表格和原生 HTML `<table>` 都会在正文宽度内分配各列并让单元格文字换行，不再显示横向滚动条。该模式适合阅读和打印预览；它会暂时忽略此前手动调整的 Markdown 列宽，以保证表格不会溢出正文。

将鼠标移到某一列的边界，先出现的是加列操作。若要调整列宽，请在边界处按住约一小会儿后再左右拖动；列宽会跟随鼠标实时变化，松开鼠标后保留这次宽度。手动调整代表你明确指定了版式，此后 HorseMD 会优先使用保存的列宽，而不再自动覆盖它。普通点击和短暂悬停不会改变列宽。

在宽表最右侧进行加列、点击表头上方的列选择/对齐菜单，或调整列宽时，表格会停留在当前横向位置，不会自动跳回第一列，也不会在操作瞬间闪回左侧。

## 单元格内换行

在表格单元格内按 Enter 或 Shift+Enter 会插入换行。保存时 HorseMD 将其序列化为 `<br>`：

```md
| 姓名 | 说明 |
| --- | --- |
| 小马 | 第一行<br>第二行 |
```

GFM 表格的每一行必须保持为源码中的单行。使用 `<br>` 可以让内容重开后仍然正确解析，不会破坏后续行列。

## 源码模式编辑

源码模式中需要自行保持竖线数量和分隔行。单元格文字包含竖线时使用反斜杠转义；复杂内容建议切回富文本检查结果。

::: warning 不支持跨行跨列
标准 Markdown 表格没有 `rowspan` 和 `colspan`。需要复杂表格时可以使用受支持的原生 HTML 表格，但部分 Markdown 平台可能不会采用相同样式。
:::
