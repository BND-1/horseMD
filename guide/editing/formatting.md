# 文字与段落格式

<span class="version-badge">适用于 HorseMD v0.13.125</span>

HorseMD 支持直接输入 Markdown 语法，也支持选区工具栏、快捷键和斜杠菜单。

## 段落类型

在空段落开头输入以下内容并按空格：

| 输入 | 结果 |
| --- | --- |
| `# `～`###### ` | 一到六级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 任务列表 |

有序列表的编号由编辑器按顺序自动生成：输入 `1. ` 开始列表后，按回车新建的下一项会显示为 `2. `、`3. `…… 即使你输入的数字与实际序号不同，Markdown 渲染和源码也会保持正确的连续编号，不会因为残留的输入内容把下一项改回 `1. `。

空列表项（如单独一行的 `1. ` 或 `- `）在源码中始终保留标记后的空格，不会被写成裸的 `1.` 或 `-`；后续在空项内输入正文（包括输入法提交的整段文字）时，文字会写入该项内部，而不会在文档中新增一个带列表标记的独立段落，也不会把正文写到列表外面留着一个空项。

退出有序列表后，如果先输入单独的 `-`，再按空格创建无序列表，编辑器会保留这个已确认的 marker，只在对应位置创建一个新的无序列表项，不会复制前面的列表项或把 marker 写到其他段落。
| `> ` | 引用 |
| `` ``` `` | 代码块 |

在文档中间已有空代码块时，点击代码区后直接逐字输入，内容会保持在开闭围栏之间；切换源码、保存和重新打开也不会把首段代码写到围栏外。代码块内部编辑会按围栏边界单独同步，不会被前后列表或段落的格式差异影响。

也可以输入 `/` 后选择对应块。`Ctrl+1`～`Ctrl+6` 将当前段落转换为标题，`Ctrl+0` 转回正文。

任务列表可直接点击方框切换完成状态。勾选或取消勾选后，文档会进入未保存状态；保存并重新打开文件时，状态仍会保留。Markdown 源码只会把对应项目的 `[ ]` 与 `[x]` 互相替换，不会改写其他列表项。

## 转换列表类型

在桌面端富文本模式中，右键普通列表的任意一项，悬停“列表”后选择转换项：无序列表可转为有序列表或待办清单，有序列表可转为无序列表或待办清单。转换只作用于当前所在层级，保留项目文字；父列表和子列表不会被一起改动。

转换不会顺带整理整棵列表的源码。即使外层是松散列表、内层是紧凑列表，HorseMD 也只改变你操作层级的标记，保留子列表原有缩进和空行；转换后立即继续打字、切换源码、保存并重新打开，结构仍保持一致。

任务列表也可以转换为无序或有序列表；转换后会移除勾选状态，但项目文字和子列表保持不变。列表的右键菜单不会显示正文或标题等无法作用于列表项的操作。

普通正文段落右键后，悬停“转换为”也可直接变为无序列表、有序列表或待办清单。转换作用于你右键的那一段，而不是之前光标所在的其他段落；待办清单会以未勾选状态创建。

## 文字格式

选中文字后默认会出现浮动工具栏，可设置粗体、斜体、删除线、高亮、行内代码和链接。常用快捷键包括 `Ctrl/Cmd+B`、`Ctrl/Cmd+I`，黄色高亮使用 `Ctrl/Cmd+Alt+H`。

偏好更安静的写作界面时，可在“设置 → 编辑器 → 编辑”关闭“选中文字时显示浮动工具栏”。关闭后，选中文字并右键，一级菜单会显示“文字格式”“审阅标记”和“转换为”；鼠标悬停在任一项上会展开相应子菜单。子菜单包含粗体、斜体、删除线、行内代码、链接、高亮、完整审阅标记（新增、删除、替换、高亮 + 评论），以及原有的列表或块类型转换。快捷键不受影响。手机端继续使用系统原生文本选择菜单。

Markdown 源码中的 `**粗体**`、`*斜体*`、`` `代码` ``、`~~删除线~~` 和链接语法会在富文本中即时显示。切换到源码模式可以检查实际标记。

源码与富文本切换会保留当前光标和阅读位置。切回富文本后可以直接换行并继续输入，不需要等待编辑器重新定位；硬换行、表格、列表、代码块和行内图片附近也使用对应的源码位置进行恢复。

## 换行与段落

打开其他软件创建的 Markdown 时，如果同一段内使用普通单换行，例如：

```md
调研单位：示例公司
调研时间：2026 年 7 月 30 日
```

HorseMD 默认会在富文本中按两行显示，方便阅读逐行字段；切换源码、保存和导出都不会给文件补空行、尾随空格或 `<br>`。偏好严格 CommonMark 合并显示时，可在“设置 → 编辑器 → 编辑”关闭“保留源码单换行”。

这项设置不改变写作按键：按 Enter 创建新段落，源码中会有一个空白行；按 Shift+Enter 创建同一段内的显式硬换行。无论设置开关如何，这两种源码语义都保持不变。鼠标点击已有普通段落的中间位置后按 Enter，再输入 `1. ` 创建列表时，源码同步会只保留这次段落拆分和列表事务，不会因为文档其他位置已有不同的列表符号而误报源码分叉。

连续按两次 Enter 留出空段落时，源码会使用普通空行表示，不会写入编辑器内部的 `<br />` 占位。即使连续创建多个中间空段后再输入正文、空有序列表和后续正文，源码也会保留每个段落的边界，不会提示无法保存。逐字输入 `-`、`*` 或 `+` 加空格创建无序列表时，切换源码和保存后会保留你实际使用的列表符号；在该列表中按 Enter 新增项目也会沿用同一符号。已有文档中间也可以连续写正文 → 有序列表 → 无序列表，或连续创建两个独立的有序列表；表格末尾按回车创建列表时，也会先保留首个有序列表，再把后续无序列表的内容写入对应列表行。切换源码和保存不会把新列表的标记错写到其他列表，也不会把第二个列表嵌套成前一个列表的后续项。延迟回调中的旧列表输入意图也不会串到后续列表，`1.`、`1)` 等实际输入标记会保持在对应列表上；在有序列表中输入正文后按 Enter，新建的下一项会保留正确的 `2.` 编号，不会被之前的 `1.` 输入意图重写。源码同步还会校验列表项数量、空项目槽位和有序编号；如果一次结构事务无法证明这些槽位与富文本一致，会暂停源码切换/保存并提示，而不会静默写入不完整源码。无序列表的空项中连续按两次 Enter 退出列表时，只会删除当前空项，后面的列表项和空行分隔会保留，不会因为编辑器内部的 `<br />` 占位而丢掉下一项。有序列表的空项中如果先输入空格、再输入法输入正文并继续输入空格，源码也会把这些空格保持为普通空格，不会留下 U+200B 隐藏占位符。

行内代码可按标准 Markdown 顺序逐字输入：先输入一个左反引号，再输入正文，最后输入一个右反引号。**在最后一个反引号输入之前，HorseMD 会保留字面的反引号和正文，不会提前进入代码样式；闭合后才渲染。**闭合后的光标位于代码外，可直接继续写普通正文。点击已有行内代码可以继续编辑；光标位于代码尾部时按 `→`，或位于首部时按 `←`，都能直接退出代码样式。方向键不会跳过正文字符，也不会在源码中增加隐藏字符。需要输入两个或三个普通反引号时可直接连续输入，不会吞掉前一个字符；同一行输入 ```` ```你好``` ```` 会保持普通正文，源码、保存和重新打开也不会额外增加反斜杠。

正文结束后仍会保留一段舒适的滚动留白。末段已有内容时，点击正文下方任意可见空白，包括页面容器之外靠近窗口底部的位置，会自动新建下一段并把光标放进去；末尾本来就是空段落时则直接复用，继续写作不必先按回车，也不会因重复点击产生多余空行。

::: tip 粘贴 Markdown
在普通正文中粘贴包含标题、列表或表格的 Markdown，会按结构解析；在代码块中粘贴则保持原始文本，不会被重排。
:::

从微信公众号等网页编辑器复制富文本时，HorseMD 会把用于排版的 `section`、`div` 视觉段落转换为正常段落，同时保留加粗、斜体、列表等可识别格式，避免多段内容挤成一段。
