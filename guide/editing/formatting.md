# 文字与段落格式

<span class="version-badge">适用于 HorseMD v0.12.10</span>

HorseMD 支持直接输入 Markdown 语法，也支持选区工具栏、快捷键和斜杠菜单。

## 段落类型

在空段落开头输入以下内容并按空格：

| 输入 | 结果 |
| --- | --- |
| `# `～`###### ` | 一到六级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 任务列表 |
| `> ` | 引用 |
| `` ``` `` | 代码块 |

也可以输入 `/` 后选择对应块。`Ctrl+1`～`Ctrl+6` 将当前段落转换为标题，`Ctrl+0` 转回正文。

## 转换列表类型

在桌面端富文本模式中，右键普通列表的任意一项，悬停“列表”后选择转换项：无序列表可转为有序列表或待办清单，有序列表可转为无序列表或待办清单。转换只作用于当前所在层级，保留项目文字；父列表和子列表不会被一起改动。

任务列表也可以转换为无序或有序列表；转换后会移除勾选状态，但项目文字和子列表保持不变。列表的右键菜单不会显示正文或标题等无法作用于列表项的操作。

普通正文段落右键后，悬停“转换为”也可直接变为无序列表、有序列表或待办清单。转换作用于你右键的那一段，而不是之前光标所在的其他段落；待办清单会以未勾选状态创建。

## 文字格式

选中文字后默认会出现浮动工具栏，可设置粗体、斜体、删除线、高亮、行内代码和链接。常用快捷键包括 `Ctrl/Cmd+B`、`Ctrl/Cmd+I`，黄色高亮使用 `Ctrl/Cmd+Alt+H`。

偏好更安静的写作界面时，可在“设置 → 编辑器 → 编辑”关闭“选中文字时显示浮动工具栏”。关闭后，选中文字并右键，一级菜单会显示“文字格式”“审阅标记”和“转换为”；鼠标悬停在任一项上会展开相应子菜单。子菜单包含粗体、斜体、删除线、行内代码、链接、高亮、完整审阅标记（新增、删除、替换、高亮 + 评论），以及原有的列表或块类型转换。快捷键不受影响。手机端继续使用系统原生文本选择菜单。

Markdown 源码中的 `**粗体**`、`*斜体*`、`` `代码` ``、`~~删除线~~` 和链接语法会在富文本中即时显示。切换到源码模式可以检查实际标记。

行内代码可按标准 Markdown 顺序逐字输入：先输入一个左反引号，再输入正文，最后输入一个右反引号。编辑期间 HorseMD 会临时显示左右反引号，光标离开、编辑器失焦或输入右反引号后收起为渲染样式；这些临时边界不会重复写入或污染源码。需要输入多个普通反引号时可直接连续输入，不会吞掉前一个字符。点击已有行内代码可继续编辑，点击代码外后输入的仍是普通正文。

正文结束后仍会保留一段舒适的滚动留白。末段已有内容时，点击正文下方任意可见空白，包括页面容器之外靠近窗口底部的位置，会自动新建下一段并把光标放进去；末尾本来就是空段落时则直接复用，继续写作不必先按回车，也不会因重复点击产生多余空行。

::: tip 粘贴 Markdown
在普通正文中粘贴包含标题、列表或表格的 Markdown，会按结构解析；在代码块中粘贴则保持原始文本，不会被重排。
:::

从微信公众号等网页编辑器复制富文本时，HorseMD 会把用于排版的 `section`、`div` 视觉段落转换为正常段落，同时保留加粗、斜体、列表等可识别格式，避免多段内容挤成一段。
