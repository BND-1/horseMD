# 链接与附件

<span class="version-badge">适用于 HorseMD v0.13.29</span>

## 打开和编辑链接

单击链接就会打开（拖动选中链接文字不会打开，方便复制）。按住 `Cmd` / `Ctrl` 点击也可以。

鼠标在链接上停一下，会出现链接卡片：

- 点卡片上的地址：打开链接。
- 复制：复制链接地址。
- 编辑：同时修改链接**文字**和**地址**，按 `Enter` 或点「确定」，`Esc` 取消。
- 取消链接：去掉链接，保留文字。

也可以用键盘：光标在链接里按 `Cmd/Ctrl+K` 编辑这个链接；选中一段文字按 `Cmd/Ctrl+K` 把它变成链接（不选文字时会新插入一个链接）。修改只改动源码里这个链接本身，带标题的 `"标题"`、尖括号地址 `<…>`、链接里的粗体等写法都会保留；引用式链接 `[文字][1]` 改地址后会变成行内写法，`[1]:` 定义不动（别的地方可能也在用）。

打开时：

- `https://` 和 `http://` 使用系统默认浏览器打开。
- `#标题` 跳到当前文档里的这个标题，例如 `[见第二节](#第二节)`。英文标题也可以写成小写加连字符：`#second-part`。
- `.md` / `.markdown` 文件在 HorseMD 里用新标签页打开（已打开就切过去）。写成 `其他笔记.md#标题` 会打开后跳到那个标题。
- 其他本地文件（PDF、图片、文件夹等）交给系统里关联的应用打开。
- `./`、`../` 等相对路径按当前 Markdown 文件所在目录解析。
- 裸本地绝对路径也可直接使用：macOS/Linux 的 `/absolute/path/文件.md`，以及 Windows 的 `C:/.../文件.md` 和 UNC 网络路径；无需手动写成 `file:///`。

包含空格或中文的本地路径建议使用尖括号：

```md
[原型文件](<./App原型与截图/原型.html>)
```

例如，下面的链接会在 HorseMD 里打开这个笔记（把示意路径替换为你的真实位置）：

```md
[文件](</absolute/path/to/notes.md>)
```

链接指向的文件或标题不存在时，HorseMD 会提示。出于安全原因，未知或危险协议不会交给操作系统执行。

## 插入附件

桌面端可以通过“文件 → 插入附件…”或命令面板选择 PDF、DOCX、ZIP、音频等普通文件。当前 Markdown 必须先保存，因为附件目录需要以文档位置为基准。

HorseMD 会：

1. 在文档同级创建 `assets/` 文件夹。
2. 将附件复制进去，重名时生成不冲突的文件名。
3. 在当前光标处插入普通 Markdown 链接。

```md
[report.pdf](<assets/report.pdf>)
```

附件只作为链接，不在编辑器内预览。移动文档时应一起移动 `assets/`。移动端暂不提供附件复制入口，可使用系统分享功能处理文件。
