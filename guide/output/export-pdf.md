# 导出 PDF

<span class="version-badge">适用于 HorseMD v0.12.44</span>

## 打开导出中心

可使用任意一种入口：

1. 按 `Ctrl/Cmd+Shift+E`。
2. 打开“文件”菜单，选择“导出为 PDF”。
3. 按 `Ctrl/Cmd+P` 打开命令面板，搜索“导出 PDF”。
4. 右键当前文档标签，或右键工作区中的 Markdown 文件，选择“导出为 PDF”。

HorseMD 会打开独立的 PDF 导出中心：左侧调整设置，右侧显示真实 PDF 分页预览。确认后点击“导出 PDF”，选择保存位置；生成完成后会使用系统默认 PDF 阅读器打开。

![PDF 导出中心，左侧为页面与结构设置，右侧为真实分页和书签预览](/images/v0.12.10/pdf-export.png)

设置改变后，预览会自动更新；最终保存的就是当前预览所使用的同一份 PDF。预览生成期间“导出 PDF”暂时不可点击，但正文字号、页眉、页脚、页码等设置仍可继续调整。HorseMD 会等待当前打印安全结束、丢弃过期结果，并只生成最后一次设置，不会让多个打印任务互相冲突。若远程图片仍在加载或确实加载失败，导出中心会分别显示图片数量；无图片文档不会显示资源警告。生成失败时设置会保留并可直接重试，在系统保存窗口中取消会返回导出中心。

表格导出会保留富文本中当前的自然总宽度、各列比例和紧凑行距。内容较少的表格保持紧凑，不会强制拉满页面；超宽表格会缩到打印区域内并让长内容换行。若在富文本中手动调整过列宽，PDF 也会使用调整后的实际比例。表格单元格内部不会套用正文段落的上下间距，因此打印预览中的每行留白会与编辑器保持同一密度规则。

## 页面与分页

- 页面尺寸：A4、A3、Letter，或输入 50–1000 mm 的自定义宽高。
- 页面方向：纵向或横向。
- 页边距：普通、窄、宽，或分别设置上、右、下、左边距。
- 正文字号：可在 8–24pt 之间以 0.5pt 为步进调整，默认 11pt；标题、表格、代码和间距会随正文等比变化。
- 整体缩放：在 50%–200% 之间同时调整文字、图片、图表和页面留白。只想改变阅读字号时使用“正文字号”，需要把整份版面一起放大或缩小时再使用“整体缩放”。
- 代码块、表头、提示块和高亮文字的背景色会默认保留。
- 自动分页：由排版引擎根据内容长度换页。
- 长表格会尽量保持完整内容并按页面宽度换行；很宽的列和连续长文本会自动折行，避免只打印表格的一部分。
- 按标题分页：可让一级、二级或三级标题从新页开始。
- 按分隔符分页：Markdown 的 `---` 结束当前页，适合手工控制章节边界。

## 目录与 PDF 大纲

“在正文前添加目录页”和“生成 PDF 导航大纲（书签）”是两个独立选项：

- **在正文前添加目录页**：在正文前增加一页可见、可打印的目录，可以选择收录到 H1–H6 的哪一级，并决定正文是否另起一页。
- **PDF 导航大纲（书签）**：把标题作为书签写入 PDF 文件，可在 Acrobat、系统预览等阅读器侧栏中导航，不占用正文页面。HorseMD 预览区左上角的大纲按钮读取的也是生成后 PDF 内的真实书签。

目录条目保留标题层级并可点击跳转。只想要阅读器导航、不想多打印一页时，仅开启 PDF 书签即可。

## 页眉、页脚与范围

- 文档标题可以在导出前修改，不会改动 Markdown 文件名或正文。
- 页眉可以显示文档标题、自定义文字和日期。
- 页脚可以显示自定义文字和“当前页 / 总页数”。
- 页码范围留空表示全部页面；也可以输入 `1-5, 8, 11-13`。不合法的倒序范围会在导出前提示。

右侧工具栏显示当前页和总页数，并支持缩小、放大和恢复 90% 预览比例。

导出内容来自当前富文本结构，但会移除：

- 代码块工具栏和复制按钮。
- 表格拖拽手柄。
- 块菜单、加号按钮和编辑器辅助控件。
- 查找高亮等临时界面状态。

CodeMirror 普通代码块会转换为 `<pre><code>`，确保打印内容稳定。段落 LaTeX 公式（`$$...$$`）会导出为可打印的 MathML，而不是打印原始 LaTeX 源码或公式编辑按钮。Mermaid 流程图、时序图、饼图、类图、状态图和 ER 图会导出为保持原始比例的 SVG；即使图表尚未滚动到屏幕内，导出也会主动完成渲染。语法错误或超时的图表保留源码，不会阻止其余内容导出。极长的行外公式会在导出阶段按顶层运算符分成多行，不会缩小字号或裁切内容。

PDF 使用独立打印样式。生成预览前，HorseMD 会把当前文档中的本地图片和网络图片暂存到本次打印目录，含空格、中文或 `%20` 的相对图片路径也会按文档位置解析；因此最终 PDF 不依赖打印窗口再次访问原始地址。只有图片确实无法读取、下载失败、超过安全大小限制或超时，才会显示资源警告。

## 分屏时导出

先点击需要导出的编辑栏，再执行导出。HorseMD 会读取当前聚焦文档，不会固定导出左栏或第一个标签。

::: info 移动端
iOS 和 Android 不提供桌面 PDF 导出。可以通过系统分享把 Markdown 发送到支持打印或 PDF 转换的应用。
:::
