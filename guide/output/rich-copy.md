# 富文本复制

<span class="version-badge">适用于 HorseMD v0.13.228</span>

在桌面富文本模式选中内容后，右键选择菜单首项“复制”，也可以按 `Ctrl/Cmd+C`。HorseMD 会同时提供纯文本、带内联样式的 HTML 和内部使用的 Markdown，目标应用会选择自己支持的格式。

适合粘贴到：

- 微信公众号编辑器。
- 邮件正文。
- Notion、语雀和支持富文本粘贴的知识库。
- Word 或其他办公软件。

标题、段落、列表、引用、表格、代码和链接会尽量保留当前主题下的可读样式。编辑器专用控件不会被复制，例如代码块复制按钮、表格手柄和块级菜单。

若需要复制整个代码块，点击代码块右上角的“复制”。HorseMD 会读取完整代码内容，而不是只读取当前屏幕里渲染的行；超过 100 行的长代码也会保留第一行、最后一行、空行和原始换行。

## 右键复制选区

“复制”始终位于桌面富文本右键菜单首项，不依赖浮动选区工具栏是否开启。没有选区时按钮不可用；点击复制会保留弹出菜单前选中的内容。若文档在菜单打开后发生变化，请重新选择，不会悄悄复制另一个版本的文字。

代码块中只复制所选范围，不自动扩大成整个代码块，也不会受可见代码行数限制。源码与预览并排时，右侧只读预览可以选中复制，但不会出现修改格式的操作。移动端继续使用系统选区菜单。

## 粘贴到纯文本应用

粘贴到记事本、终端或普通输入框时，只会得到实际选中的文字。正文前后不会增加空行，只选中有序列表里的文字也不会自动多出 `1. `。如果富文本中按多行显示了源码里的普通单换行，复制结果也会保持这些换行，不会粘成一整行。

选区同时包含正文和列表时，普通换行、显式硬换行及代码中的空行也会保留；不会因为选到了列表就把其他正文拼成一行。复制整个列表结构会提供对应标记，单独选中列表里的文字则不增加标记。

在 HorseMD 内部复制和粘贴时，应用会使用单独的 Markdown 通道恢复列表、加粗、行内代码等结构；这不会污染外部应用收到的纯文本。

列表项含有多个段落、引用或代码块时，带格式复制会保留这些结构的边界；不会为了让编号同行而把后续段落拼到第一段末尾。

## 只需要 Markdown 源码

切换到源码模式后再复制，得到的是原始 Markdown 文本。也可以直接从磁盘读取 `.md` 文件。

::: tip 目标平台会二次处理样式
富文本复制不能强制目标应用接受所有 CSS。发布前应在目标平台预览，尤其检查表格宽度、代码背景、图片和字体。
:::
