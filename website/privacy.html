HorseMD 隐私政策

生效日期：2026 年 11 月 16 日

HorseMD 是一款开源的 Markdown 编辑器，有 iPhone / iPad、安卓和 Windows、macOS、Linux 桌面版。我们（HorseMD 的开发者）不收集你的任何数据。

  • 没有账号：使用 HorseMD 不需要注册或登录。
  • 没有统计和广告：App 里没有统计、追踪或广告代码。
  • 文档在你自己手里：文档保存在你的设备上（iOS 上在「文件」App → 我的 iPhone → HorseMD），或者在你自己选的文件夹里。我们看不到，也不会上传。
  • 云同步只连你自己配置的服务：如果你打开云同步，文档会直接同步到你填写的云服务（例如坚果云、Nextcloud、你自己的 NAS 或 S3 存储），不经过我们的任何服务器。账号和密钥只保存在你的设备上（iOS 钥匙串、安卓加密存储、桌面系统的安全存储）。那项服务的隐私条款由它自己负责。
  • 导出和分享：导出的 PDF、HTML 等文件在你的设备上生成，交给你选择的位置或 App，我们拿不到。
  • 图床是你自己配置的（桌面版）：如果你配置了图床，插入的图片会直接上传到你填写的服务，不经过我们。
  • 检查更新（桌面版）：App 会向 GitHub 查询有没有新版本，下载时可能经过公开的 GitHub 加速镜像。这些请求不带任何你的文档或个人信息。
  • 购买：在 App Store 购买由 Apple 处理，我们收不到你的付款信息或 Apple 账号信息。
  • 外部链接：点开文档里的网页链接会跳到系统浏览器，之后的情况由对应网站的隐私政策约束。

HorseMD 的全部源代码公开在 GitHub，任何人都可以检查上面这些说法。

有问题请在 GitHub Issues 留言。本政策如有变化，会更新在这个页面上。

HorseMD Privacy Policy

Effective: 16 November 2026

HorseMD is an open-source Markdown editor for iPhone / iPad, Android and Windows, macOS and Linux. We, the developers of HorseMD, do not collect any of your data.

  • No account: you do not need to sign up or sign in.
  • No analytics or ads: the app contains no analytics, tracking or advertising code.
  • Your documents stay yours: they are stored on your device (on iOS, in the Files app under On My iPhone → HorseMD) or in a folder you choose. We cannot see them and they are never uploaded to us.
  • Cloud sync only talks to the service you set up: if you turn on cloud sync, documents sync directly with the cloud service you enter (for example Nextcloud, your own NAS or S3 storage), never through a server of ours. Accounts and keys are stored only on your device (the iOS Keychain, Android encrypted storage, the desktop system's secure storage). That service's own privacy terms apply.
  • Export and sharing: exported PDF, HTML and other files are made on your device and go where you choose. We never receive them.
  • Image hosting is yours (desktop): if you set up an image host, images go directly to the service you entered, not through us.
  • Update checks (desktop): the app asks GitHub whether a new version exists, and downloads may go through public GitHub download mirrors. These requests carry none of your documents or personal information.
  • Purchases: App Store purchases are handled by Apple. We do not receive your payment details or Apple Account information.
  • External links: web links open in your system browser, and the linked site's privacy policy applies.

All of HorseMD's source code is public on GitHub, so anyone can check these statements.

Questions? Open an issue on GitHub Issues. Any change to this policy will be posted on this page.
